O que é isto, e o que se espera de quem lê

O Lumus é um app de jogos educativos para crianças, sem anúncio, sem cobrança e sem coleta de dados, dado de graça a famílias. Esta parte é a que acompanha a escola: alfabetização, ortografia e interpretação de texto, do 1º ao 5º ano.

As perguntas do app não são escritas uma a uma: elas são geradas a partir das tabelas abaixo. Uma sílaba separada errado aparece em quatro jogos diferentes. Por isso pedimos a revisão dos dados, e não das telas.

O que procurar

  1. A separação de sílabas está certa? É a linha mais importante deste documento — é o que a criança copia para o caderno.
  2. A figura basta para saber que palavra é? Na ortografia, é a figura que faz a pergunta ter uma resposta só.
  3. Dá para defender outra alternativa? Pergunta com duas respostas certas é pergunta errada — e a criança é reprovada por acertar.
  4. A regra está dita do jeito que a escola ensina? Se a sua turma aprende com outras palavras, vale mais a sua.
  5. O degrau está no lugar? 1 é 1º ano, 4 é 5º. Palavra fácil demais no degrau alto entedia; difícil demais no degrau baixo desiste.

Como marcar

Cada linha tem um código à esquerda (PAL-014, LEI-003.2…). Basta escrever o código e o que está errado — numa mensagem, num papel, do jeito que for mais fácil. Não é preciso abrir nada de programação.
